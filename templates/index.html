Here is a list of all available commands for the bot. The bot has the prefix "%" by default. These commands can be run using both the legacy prefix and the new slash command system.

/trackme
Begins to track your Spotify listening history for the specified amount of time.
/tracklist
Displays the list of users currently being tracked and how much time is remaining on their tracking session.
/stoptrack
Halts your current tracking session.
/autotrack
Enables/disables a feature that allows the bot to begin a tracking session as soon as you start listening.
/song
Displays the song that a user is currently listening to.
/history
Shows the last 5 songs you've listened to.
/minutes
Shows how many minutes you've listened to for the current week, this month, and all-time.
/topartists
Shows the top 10 artists a user has listened to.
/link
Connect your Spotify account to the bot to start tracking your listening history.
/unlink
Disconnect your Spotify account and stop tracking.
/ping
Displays the current latency of the bot, which is also shown on this website.
/cleanse
An admin-only command that deletes all messages sent by the bot within the last hour. (This command is largely redundant now, simply because the bot now sends all of its messages in its own channel if present).
